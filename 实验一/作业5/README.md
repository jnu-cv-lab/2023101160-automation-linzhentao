
 Image Geometric Transformation & Document Perspective Correction

OpenCV 实现图像几何变换 + 倾斜文档自动校正

功能
- 生成彩色测试图（矩形、圆形、平行线、垂直线）
- 三种几何变换：相似变换、仿射变换、透视变换
- 倾斜文档透视畸变校正（自动识别图片格式）

文件说明
- `test_first.jpg` - 几何变换测试图
- `test_fin.jpg` - 待校正的倾斜文档图
- `transform_*.jpg` - 三种变换结果
- `correct_final_校正完成图.jpg` - 校正后输出

运行环境
Python + OpenCV + numpy
