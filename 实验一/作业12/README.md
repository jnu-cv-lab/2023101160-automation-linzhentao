
# 棋盘格相机标定项目（OpenCV Python）
## 项目简介
本项目基于OpenCV实现标准棋盘格相机标定，完成内角点检测、亚像素角点优化、相机内参/畸变系数求解、重投影误差计算、图像去畸变矫正全流程，适用于课程相机标定实验作业。

### 核心功能
1. 批量读取本地15张棋盘格标定图片（`img1.jpg ~ img15.jpg`）
2. 图像预处理：高斯模糊降噪+直方图均衡，解决屏幕反光导致角点识别失败问题
3. 棋盘格内角点粗检测 + 亚像素精度优化
4. 求解相机内参矩阵K、5维畸变系数D、每张图片旋转平移外参
5. 计算全局重投影误差、单张平均重投影误差，评估标定精度
6. 生成角点绘制效果图、原图、去畸变完整图、裁剪无黑边矫正图
7. 自动创建输出文件夹，保存所有结果图像
