计算机视觉实验三：图像缩小、恢复与频域分析
本项目为计算机视觉课程实验，实现图像下采样、插值恢复、空间域质量评价及频域分析。

实验内容
1. 图像读取与灰度预处理
2. 图像1/4下采样：直接下采样、高斯预滤波抗混叠下采样
3. 图像尺寸恢复：最近邻插值、双线性插值、双三次插值
4. 质量评价：计算MSE与PSNR并对比
5. 频域分析：二维傅里叶变换（FFT）频谱对比
6. 变换域分析：二维离散余弦变换（DCT）与低频能量占比统计

环境依赖
- Python 3.x
- OpenCV-Python
- NumPy
- Matplotlib

文件结构
- homework3.py：实验主程序
- 1.jpg：输入灰度图像
- experiment_result.png：实验结果输出图
- README.md：项目说明文档
- 实验报告文档：实验原理、结果与分析

 运行方式
```
python homework3.py
```

 实验结论
1. 高斯预滤波可有效降低下采样混叠失真。
2. 图像恢复质量：双三次插值最优，双线性插值次之，最近邻插值效果较差。
3. 下采样与插值操作会丢失图像高频信息，可通过FFT频谱直观体现。
4. 图像DCT能量高度集中于低频区域，插值恢复会进一步提升低频能量占比。
