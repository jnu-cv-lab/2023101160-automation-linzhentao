 手写数字分类 - 传统机器学习实验
使用 scikit-learn 实现 6 种传统机器学习模型完成手写数字分类任务
 
 实验内容
- 加载并展示手写数字数据集（8×8 图像）
- 按 75%/25% 划分训练集与测试集
- 将图像转为 64 维像素特征向量
- 训练模型：KNN、朴素贝叶斯、逻辑回归、SVM、决策树、随机森林
- 输出准确率、混淆矩阵、错误分类样本

环境依赖
```
numpy
matplotlib
scikit-learn
```

运行方法
直接运行 Python 脚本，自动在当前文件夹生成所有结果图片

实验结果
- 最优模型：KNN（准确率 0.9933）
- 最差模型：朴素贝叶斯（0.8556）
- 原始像素特征简单但对平移、旋转、缩放不鲁棒
