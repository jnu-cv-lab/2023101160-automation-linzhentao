图像下采样与抗混叠滤波实验 | Digital Image Processing

 实验简介
本实验实现图像下采样中的**抗混叠高斯滤波**，验证经验公式 `σ ≈ 0.45M`，并通过傅里叶变换（FFT）观察频域混叠现象。同时对比**直接下采样**、**全局高斯下采样**以及**自适应下采样**的效果差异，完成图像空域与频域的完整分析。

 实验内容
1. 理解下采样中高频混叠的产生原理
2. 实现基于高斯滤波的抗混叠下采样
3. 验证经验公式：σ = 0.45 × M
4. 使用 FFT 频谱直观展示滤波与混叠效果
5. 实现自适应下采样（根据图像梯度动态调整 σ）
6. 对比不同方案：MSE / PSNR / SSIM / 误差热力图
7. 针对人脸图像实现分区域自适应滤波（人脸小 σ，背景大 σ）

 核心结论
1. **直接下采样会产生严重混叠**，必须先滤波再下采样
2. **σ = 0.45M** 能有效抑制混叠，工程实用性强
3. **FFT 可直观观察频域混叠与滤波效果**
4. **自适应下采样优于全局固定下采样**
5. **人脸区域应使用更小 σ 保留细节，背景使用更大 σ 抑制混叠**
