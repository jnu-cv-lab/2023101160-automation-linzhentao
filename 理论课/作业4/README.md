

图像局部最高频率估计方法对比实验
对比频域FFT法与空域梯度法在图像局部最高频率估计上的一致性，为图像下采样抗混叠滤波提供参数依据。

 实验方法
1. 频域FFT法：图像分块 → FFT变换 → 提取95%能量对应的最高频率（金标准）
2. 空域梯度法：梯度计算 → 统计映射 → 快速估计局部最高频率（近似方案）

 评价指标
- 皮尔逊相关系数（Corr）：衡量线性一致性
- 平均绝对误差（MAE）：衡量全局偏差

 实验结果
- 相关系数：0.9582
- 平均绝对误差：6.5063

结论：空域梯度法与FFT法具有**高度一致性**，可作为快速近似方案。
