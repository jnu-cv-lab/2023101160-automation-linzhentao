

# 数字图像处理实验 - 图像增强算法实现

基于 Python + OpenCV 实现常见图像增强算法，对比不同算法在低对比度、噪声、高亮度图像上的处理效果。

## 实现功能
- 手动实现：全局直方图均衡化、均值滤波
- OpenCV 实现：CLAHE、高斯滤波
- 组合处理：先滤波后均衡 / 先均衡后滤波
- 结果可视化 + 直方图对比

## 实验图像
- 低对比度图像
- 含噪声图像
- 高亮度图像

## 核心算法
1. 全局直方图均衡化（手动实现）
2. 限制对比度自适应均衡（CLAHE）
3. 均值滤波 / 高斯滤波
4. 图像增强顺序对比

## 运行环境
```
Python 3.x
OpenCV
NumPy
Matplotlib
```

## 运行方式
1. 安装依赖：`pip install opencv-python numpy matplotlib`
2. 运行主程序：`python import cv2.py`
3. 查看输出图像与直方图

## 实验结论
- 全局均衡化提升对比度但易放大噪声
- CLAHE 保留细节，效果最优
- 高斯滤波在去噪与边缘保留间平衡最好
- 增强顺序：先去噪 → 后均衡化效果更佳
